# Building an AI NPC Detective Game

## Problem

기존 챗봇 데모는 재미는 있지만 게임성, 일관성, 운영 관점이 약했다.
그래서 짧은 플레이타임 안에서도 추론 재미와 기술적 설명력을 동시에 보여주는 프로젝트를 목표로 했다.

## Approach

- 상태머신으로 게임 흐름을 고정해 분기 복잡도를 제어했다.
- NPC 대화는 스키마 검증 + 가드레일 + 메모리 검색으로 안정성을 확보했다.
- 운영 지표 수집 계층을 별도로 두어 응답시간/토큰/캐시 히트를 관측했다.

## Challenges

- 자유 텍스트 응답에서 포맷 깨짐이 빈번했다.
- 동일 질문 반복 시 비용이 증가했다.
- 힌트 강도를 조절하지 않으면 게임 난이도가 급격히 변했다.

## Solutions

- `response_format: json_object`와 스키마 검증 실패 fallback을 적용했다.
- 세션/NPC/질문/증거 조합 기반 캐시를 넣어 중복 호출을 줄였다.
- 힌트 레벨을 단계화(`hintLevel`)해 점진적 유도를 구현했다.

## Outcome

- 코어 루프를 갖춘 플레이 가능한 버전을 구현했다.
- 운영 지표 대시보드로 성능/비용 최적화 포인트를 빠르게 찾을 수 있게 되었다.
- 이력서에서 AI 품질, 아키텍처, 운영 역량을 동시에 설명할 수 있는 프로젝트가 완성되었다.
