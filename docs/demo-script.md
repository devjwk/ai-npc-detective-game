# Demo Script (2-3 minutes)

## 0:00 - 0:20 Problem

- "이 프로젝트는 AI NPC 대화 일관성과 추리 게임 재미를 동시에 잡는 것이 목표입니다."

## 0:20 - 1:00 Core Loop

- 메인 화면에서 세션 시작
- 장소 이동 -> 단서 수집
- NPC 선택 후 질문 입력
- 힌트 호출로 진행 막힘 해소

## 1:00 - 1:40 AI Quality

- 응답 JSON 검증 구조 설명
- 프롬프트 인젝션/금지 토픽 가드레일 시연
- 메모리 검색으로 같은 사건 맥락 유지 예시

## 1:40 - 2:20 Ending + Metrics

- 용의자 지목 후 엔딩 표시
- `/admin`에서 평균 지연시간, 토큰, 캐시 히트율 확인
- 에러 이벤트 추적 화면 소개

## 2:20 - 3:00 Engineering Impact

- 상태머신 분리로 분기 복잡도 제어
- 캐시/요약으로 비용 최적화
- 문서(PRD/아키텍처/트러블슈팅) 기반 운영 가능 상태 강조
