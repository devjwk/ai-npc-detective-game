# Resume Bullets

- AI NPC 추리 게임을 Next.js 기반으로 설계/구현하여 `탐색 -> 대화 -> 추론 -> 엔딩` 상태머신 코어 루프를 완성하고 20~30분 플레이 가능한 에피소드를 배포 가능 형태로 구축
- LLM 대화 파이프라인에 JSON 스키마 검증, 프롬프트 인젝션 차단, 금지 주제 가드레일을 적용해 응답 안정성과 캐릭터 일관성을 강화
- 대화 메모리 검색(RAG-lite)과 응답 캐시를 도입해 반복 질의 처리 효율을 개선하고 토큰 비용 최적화를 위한 기반 지표를 설계
- API 지연시간/토큰/캐시 히트율/에러 이벤트를 수집하는 운영 계층과 관리자 대시보드를 구현하여 성능/신뢰성 관측성을 확보
- PRD, 아키텍처, 성능 리포트, 트러블슈팅 문서를 체계화해 프로젝트의 기획-개발-운영 전 과정을 포트폴리오로 문서화
